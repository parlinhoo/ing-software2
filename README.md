# ing-software2

## Software de Registro de Incidentes

### PASOS PARA EJECUTAR

1. Ejecutar npm install dentro de api/ y main/ por separado
2. Ejecutar docker compose up -d dentro de la raíz del proyecto (ing-software2/)
3. Ejecutar npm run dev dentro de api/ y main/ a la vez
4. Ingresar a la página usando el link provisto por Vite (usualmente http://localhost:5173)
